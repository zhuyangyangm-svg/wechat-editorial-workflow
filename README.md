# 公众号图文写作与终审流程

一份可复用的 Agent Skill，只保留通用流程框架，不附带任何账号资料、业务案例或私有素材。

**流程：**方向、关键词或参考稿 → 检索并读取可访问的来源 → 写新稿或修改 AI/Word 稿 → AI 事实与表达自查 → 人工审核修改 → 由账号负责人预览并发布。

将 [SKILL.md](SKILL.md) 放入支持 Agent Skill 的项目技能目录即可使用。可以只提供方向和参考，也可以提交关键词、网页、样稿或现有 AI/Word 稿；AI 完成选题、写稿或改稿及首轮自查，使用者重点审核成稿。参考样稿用于学习结构和语气，不照搬原文。检索、网页读取和 Word 文件处理依赖使用者所用 AI 环境的工具，Skill 本身不提供浏览器连接。已合法打开的页面可选用 [BrowserSkill](https://github.com/Tencent/BrowserSkill) 等浏览器工具读取，但需另外配置。

AI 自查时可以选用第三方自然表达工具，例如 [de-ai-flavor](https://github.com/masonweb3/de-ai-flavor) 或 [stop-slop-cn](https://github.com/Gawg-AI/stop-slop-cn)。本仓库只链接这些工具，没有复制或安装其内容；BrowserSkill 也需在使用者环境中单独配置。润色工具不能代替事实核查，也不能凭“AI 味分数”自动放行稿件。

本仓库不接入微信公众号后台，不提供付费内容访问权限，不自动生成图片或发布内容。无法读取的来源须标明，不凭标题或摘要补写正文。
