# 公众号图文写作与终审流程

一份可复用的 Agent Skill，只保留通用流程框架，不附带任何账号资料、业务案例或私有素材。

**流程：**原始资料 → 事实底稿 → 初稿 → 人工审核 → 自然表达轻改 → 人工终审与手机预览 → 由账号负责人发布。

将 [SKILL.md](SKILL.md) 放入支持 Agent Skill 的项目技能目录即可使用。调用时提供选题、目标读者、原始资料和账号风格；资料不足时，技能应指出缺口。

自然表达轻改可以选用第三方工具，例如 [de-ai-flavor](https://github.com/masonweb3/de-ai-flavor)。本仓库只链接它，没有复制或安装其内容。润色工具不能代替事实核查，也不能凭“AI 味分数”自动放行稿件。

本仓库不接入微信公众号后台，不自动读取文章、生成图片或发布内容。
